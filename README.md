# Visor 3D · FIR Panamá (MPZL)

Visor 3D para estudiar las rutas ATS del FIR Panamá con relieve real, a partir de
los datos del AIP Panamá.

**Autor:** Delta Charlie · [github.com/Bugaryy](https://github.com/Bugaryy)
© 2026 Todos los derechos reservados — ver [LICENSE](LICENSE).

## Qué incluye
- Rutas superiores.
- Modos de vista: plano único, capas por familia y altitud por nivel de vuelo.
- Puntos significativos, VOR/DME, límites del FIR y FIR adyacentes.
- Funciona en computadora y en celular.

## Fuentes
AIP Panamá (ENR 3.1, 3.2, 3.3, 3.5, 4.1, 4.4, 6.1A, 6.1B) y AIP Colombia ENR 2.1.
Los datos que no se pudieron verificar se marcan como "pendiente de verificar"
dentro del visor (menú Acerca de).

> Material didáctico. No apto para navegación ni planificación operacional.
> Verifique siempre el AIP, AIP SUP y NOTAM vigentes.
